# Discode

Discord Bot Manager for Termux

## Setup

```bash
chmod +x setup.sh
./setup.sh
```

## Commands

```bash
discode create <name> --token <token> --prefix <prefix>
discode list
discode delete <name>
discode default <name>
discode start <name>
discode add-cmd <bot> <name> <response> --desc <description>
discode list-cmd <bot>
discode del-cmd <bot> <name>
discode plugin create <name>
discode plugin list
discode token-guide
```
